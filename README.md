# LinkVault

> Save it once. Find it instantly.

LinkVault is a private, browser-first workspace for saving important links and
organizing them with collections and tags.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Product direction

- Backendless and local-first
- Platform-aware link creation
- Fast search and filtering
- Matte light and dark themes
- Responsive desktop and mobile interface

The production site will be available at
[getlinkvault.pages.dev](https://getlinkvault.pages.dev).
